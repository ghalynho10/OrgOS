## Entities

- Issue: one document per issue, identified by `key`.
- Project: `fields.project.key`.
- Person: the `.key` of a user object, for example `fields.assignee.key` or `changelog.histories[].author.key`.
- Time entry: rebuilt from the changelog, since there is no worklog field. - Issue link: `fields.issuelinks[]`, identified by `fields.issuelinks[].id`.
- Parent relation: the child's `fields.parent.key`.
